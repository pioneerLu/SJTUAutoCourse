# 章节测试与视觉 LLM

已适配当前课程的 `onlineexamh5new.zhihuishu.com` 章节作业页，支持单选、判断、多选。使用独立命令，不与视频播放同时运行。题干使用关闭的 Shadow DOM，因此发送**整题截图及选项文本**给支持图片输入的模型。

## 登录与课程入口

章节任务优先复用已保存的登录状态，不需要先启动视频学习。如果测试入口要求重新登录，程序会转到常规登录页，使用配置账号登录（也可手动登录），完成验证后重新打开课程中的章节入口；不会反复重走测试网关的登录回跳。

章节入口依赖视频学习网站的账号会话。首次打开课程时先确认该网站登录，再进入课程目录；无需实际播放视频。同一批任务内复用仍可用的课程页和登录状态，换课、页面失效或出现登录表单时重新认证，不再逐章跳回登录页。测试入口返回视频平台时会先恢复登录再重新打开，正常 SSO 跳转保留等待时间。HTTP 400 等登录错误会明确显示，不再改写为泛化的页面超时；失败阶段、实际相关页面状态及截图保存在对应运行的诊断目录中。开启 `[script-option] enableAutoCaptcha=True`（GUI 视频学习页的“自动滑块”）后，章节登录也会自动尝试易盾滑块，复用已安装的 NumPy / OpenCV；关闭开关、依赖不可用或自动尝试失败时，仍可在浏览器手动完成验证。登录完成、失败或停止任务时会清理自动滑块任务。

读取章节、开始章节及回填时会持续检查课程目录和登录跳转。目录加载 30 秒仍未完成时，自动重新打开课程一次；出现验证码则提示在浏览器中完成，最多等待 120 秒，不自动刷新验证码。两次加载均失败时会显示中文原因，并在 `.autovisor/course-entry-errors/` 保存页面截图、去除认证参数的网络状态和未完成请求，便于区分目录接口未返回与没有章节测试入口。

## 配置与命令行

配置模板的 `[llm-option]` 中，`url` 和 `key` 预留为空；接入时填写服务商的 OpenAI 兼容接口地址（到 `/v1` 或完整 `/chat/completions`）及 Key，并填写其视觉模型名称 `model`。也可以使用 `AUTOCOURSE_LLM_URL`、`AUTOCOURSE_LLM_KEY`、`AUTOCOURSE_LLM_MODEL` 环境变量覆盖配置。未配置完整时会直接提示，不会启动作答。

```ini
[llm-option]
url =
key =
model =
timeout = 90
minConfidence = 0.8
autoSubmit = False
jsonMode = False
```

先只导出第一个章节测试，验证登录、题型和截图，无需 LLM 配置：

```powershell
.\.venv\Scripts\python.exe AutoCourse.py --export-chapter-tests --chapter-test-index 1
```

配置完成后作答第一个章节测试：

```powershell
.\.venv\Scripts\python.exe AutoCourse.py --chapter-tests --chapter-test-index 1
```

省略 `--chapter-test-index` 会依次处理全部章节测试；序号按课程目录顺序从 1 开始。只预览模型答案可使用 `--preview-chapter-tests --chapter-test-index 1`，不会回填、暂存或交卷。

## GUI、覆盖策略与模型选择

GUI 提供“视频学习 / 章节测试 / 模型设置”三个页签。在章节测试页先“读取章节”，勾选目标章节，选择模型和运行模式，再“开始所选章节”。默认模式为**生成答案预览**；另有“仅导出题目”“回填并暂存”“自动交卷”。逐题结果展示题型、答案、模型、置信度和状态，双击可以查看整题截图及解释、保存本地手动修改。低置信度题会留空，其余有效答案继续回填、暂存或交卷；手动修改的答案不受模型置信度阈值限制。

“覆盖已有答案”默认关闭，对应 `[llm-option] overwriteAnswers = False`。关闭时只补空题及重做低于当前阈值的题目，同一课程、同一章节中内容一致的高置信度及手动答案会沿用，切换模型也不会重做这些题；网页已有但无法确认置信度的选择默认保留为手动答案。勾选后，“开始所选章节”会重新请求模型并允许替换所选章节的已有答案；下方“回填并暂存所选 / 交卷所选章节”允许使用本地结果替换已有选择，不重复请求模型。显式“重试选中题”始终重新请求这一题。复用使用题目 ID、题型、题干图像及选项内容指纹，排除选中样式和选项字母排列，内容不一致时不复用；旧记录无法建立稳定指纹时仅复用整题截图一致的答案。

“覆盖已有答案”和“全选当前范围”位于“运行记录与答案”标题旁，隐藏章节列表后仍可见。全选只选择当前运行 / 测试筛选范围内的测试分组，包含尚未展开或加载的题目，不选入被筛选隐藏的其他运行；取消勾选清除选择。修改代码后需关闭旧 GUI，再重新运行 `GUI.py` 才会显示新控件。

章节列表与答案表按窗口的剩余高度分配空间，答案区优先；隐藏章节列表后，其空间自动用于答案表。进入章节测试页时收起顶部课程链接，可通过“显示课程链接”重新展开。底部日志保留三行显示，可滚动查看，避免在小窗口中挤出运行记录和回填按钮。

全选回填会略过已交卷，以及缺少 `context.json`、`questions.json` 或 `review.json` 的记录。已交卷的结果记录通常没有答案文件，单独操作时直接显示已交卷并跳过；尚未生成完整答案的记录会提示先“生成答案预览”，不会把文件缺失显示为底层系统错误。

“模型设置”中两个模型名称下拉框提供此前文本与图片样例测试通过的 `qwen3-vl-plus`、`kimi-for-coding`、`qwen3.8-max`、`MiniMax-M3`，也可手动输入其他模型名称。这是本地候选列表，接口、余额及模型能力可能变化，可用 GUI 的模型接口测试重新检查。选择并保存配置后，“章节测试”的模型选择会显示对应名称。

## 历史记录与批量回填

答案区按“运行时间与模式 → 课程与测试名称 → 题目”分组，顶部可筛选运行或测试。开始新运行时自动切换到新记录，保留旧记录；重启 GUI 后自动列出 `.autovisor/chapter-tests/` 中的本地运行，默认加载最新记录，选择其他运行或测试时再读取答案。“刷新运行记录”重新读取本地状态，“打开历史结果”可导入旧格式结果。题目详情和日志也标明来源；回填可选择测试分组或该测试下的题目，重试仅操作所选题目。

查看记录或开始章节运行时会收起课程链接及章节列表，给答案区留出空间；可用“显示课程链接”和“显示章节列表”随时展开。读取章节会展开章节列表，切回视频学习会显示课程链接。

预览完成后可按 Ctrl / Shift 多选测试分组或题目行，点击“回填并暂存所选”或“交卷所选章节”。选测试分组会处理整章，选题目行仅回填所选题目，仍遵循覆盖开关；同时选中分组和该分组的题目时按整章处理。跨章节选择会依次执行，单个章节操作错误会记录失败并继续后续章节，结束时汇总完成、跳过和失败数量；点击停止仍会立即取消后续处理。暂存时未选择的题目保留网页上的原选择；交卷会提交所在章节的整份作业。缺失、未完成、格式无效及重复的答案逐题跳过，低置信度题留空，其他有效答案继续回填与提交；默认覆盖关闭时仍保留已有手动选择。整章没有可用答案时跳过保存/交卷。程序重新核对全部题目 ID、选项 ID 和内容，适应随机排列的字母；页面核对失败只停止当前章节。查看详情和重试要求单选题目，重试只请求这一题，可切换另一模型。历史 `review.json` 和之前的 `results.json` 可以在 GUI 打开；旧记录缺少 `context.json` 时仅用于查看，需重新运行预览建立章节关联后回填。

批量回填或交卷只启动一次浏览器，逐章关闭测试和登录中转标签，保留课程页，全部结束或停止后统一关闭程序创建的浏览器；连接已有浏览器时只清理任务创建的页面。浏览器崩溃后为下一章重建会话，不重发上一章。仅包含已提交或本地数据不完整的记录时不会启动浏览器。

## 安全验证与保存确认

题目读取、核对和回填前出现安全验证时，保留测试页并暂停，GUI 显示“等待验证”，最多等待两分钟，可点击“停止”取消任务。请在浏览器手动完成验证，组件加载期间也保持等待；验证消失后重新核对题目及选项再继续。保存/交卷前若验证导致网页答案变化，会停止当前章节并要求重新回填，避免提交刷新后的空白答案。验证超时或窗口关闭会记录明确原因，继续处理其他章节。

暂存成功后，网站可能自动关闭测试页。保存时会短暂延后网站主动关页，读完响应后恢复正常关闭；响应读取最多等待 30 秒。若确认响应仍未能读取，“开始所选章节”和使用历史答案回填都会只重新读取已保存选项来核对，不重复发送暂存；交卷仍要求网站明确确认成功，不能从已有选项推断已交卷。回填或暂存失败时，会保留失败阶段、保存响应摘要、页面状态和截图；历史回填的失败记录位于该章节的 `apply-errors/` 下。

已交卷的章节再次打开时会进入“作业结果”页。程序会立即识别并显示“已交卷（跳过）”，不再等待作答控件，也不再次生成答案或回填；批量任务继续处理其余所选章节。

## 模型槽、中继与异常处理

“模型设置”支持两个配置槽。在 `[llm-model-1]`、`[llm-model-2]` 的 `model` 中分别填写服务商提供的准确模型名称，两者都应满足实际题目的图片输入要求。槽内 URL / Key 留空会继承 `[llm-option]` 的公共接口；也可分别指定。`modelProfile=1/2` 保存当前选择；旧 `model` 和 `model_ds` 分别作为两个槽的后备。环境变量 `AUTOCOURSE_LLM_URL/KEY/MODEL` 仍优先于配置文件。

GUI 可用自制算术图片测试所选模型接口，Key 默认隐藏。`retryDelay` 控制失败重试等待（第二次等待翻倍），`requestInterval` 控制题目请求间隔，默认分别为 15 和 30 秒。进度和重试信息实时显示在底部，停止会保留已生成的本地结果。视频学习页可勾选“视频任务正常结束后运行已勾选的章节测试”，接续时使用所选运行模式。

默认 `autoSubmit=False`：LLM 答案格式校验通过后回填并**暂存作业，不交卷**。低于当前阈值的题目留空并记录题号，不阻断其他题目；`autoSubmit=True` 时允许确认网站的未作答提示并交卷，仍必须收到站点成功响应。低置信度题已有旧选择时会尝试清空并核对；安全验证先暂停等待，超时、无法清空、选项 ID 不匹配、题型不支持或保存失败时停止当前章节，不自动重新交卷。题目、整题截图、答案和运行结果存放在 `.autovisor/chapter-tests/`，`result.json` 记录填充数及低置信度留空题号，`answers.json` 中留空题对应 `null`。模型置信度不代表平台评分，实际服务的连通性和答题正确率需配置后验证。

模型返回格式错误时，最多进行 3 次请求（含网络重试），提示模型纠正 JSON 和选项 ID。与页面 ID 完全一致的整数可转换为字符串；单个选项字母只有在实际选项标签中唯一匹配时才转换为 ID，不按位置猜测。空答案、未知或重复 ID、无效置信度仍会被严格拒绝，但只跳过对应题目，其余有效答案继续处理。`result.json` 的 `skipped_questions` 记录题号、题目 ID、原因及类别；原有失败/手动答案记录保持不变，方便后续重试。反复格式错误的去敏返回保存在失败记录的 `llm_diagnostics` 中；GUI 单题重试失败时另存于该测试目录的 `response-errors/`，保留原答案记录。

题目到模型的输入/输出现在由独立中继统一处理：本地网页 ID 映射为模型用的短编号，返回后再转换为真实 ID。支持常见字段别名、标量/数组、中文字段、JSON 包裹、文本分块、思考标签和明确百分比置信度；仍拒绝歧义、未知 ID 和缺失置信度。“模型设置”的中继适配器和输出约束可留空自动继承，原配置无需修改。详见 [中继结构与配置](llm-relay.md)。

其他服务需支持多模态、非流式 Chat Completions 请求，图片采用 Base64 data URL，认证使用 Bearer Key。接口能力、模型读图能力和答案正文格式需分别确认；首次接入可用 `generic` 与 `prompt`，详细示例见 [模型接入与中继](llm-relay.md)。`jsonMode=True` 仅适用于支持 `response_format=json_object` 的服务。

开发与维护说明见 [项目结构和测试方法](architecture.md)。
