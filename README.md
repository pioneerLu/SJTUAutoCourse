# AutoCourse

支持 Chrome 和 Edge 的智慧树课程学习与章节测试工具。通过图形界面添加课程、管理播放任务、配置视觉模型，并查看和复核章节答案。

## 可以做什么

- **视频学习**：管理多门课程，设置播放倍速、静音和每门课的运行时长。
- **章节测试**：读取题目，生成答案预览，查看置信度，手动修改答案，按所选章节回填、暂存或交卷。
- **模型切换**：配置两个模型；默认只重答低置信度、失败或空答案，保留内容一致的高置信度和手动答案。
- **运行记录**：按运行、课程和章节查看结果，支持多选、筛选和查看失败原因。

## 开始使用

### Windows

目前仅支持 **Windows**。准备好 **Python 3.10–3.13** 和 **Google Chrome 或 Microsoft Edge**，打开项目文件夹，在 PowerShell 中运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install ".[gui]"
.\.venv\Scripts\python.exe GUI.py
```

如果已有项目 `.venv`，无需重新创建。依赖已经安装时，直接运行最后一行即可。GUI 和视频子任务会优先使用这个虚拟环境。

## 第一次使用 GUI

1. 在窗口顶部粘贴**课程视频播放页链接**，每行一门课。支持直接粘贴 Markdown 链接和带说明的链接。
2. 打开“视频学习”，选择 **Chrome 或 Edge**，设置倍速、静音和每门课时限；时限单位为分钟，`0` 表示不限。
3. 点击“保存并开始视频学习”。账号密码可以留空，在打开的浏览器中手动登录。
4. 如果出现安全验证，按界面提示在浏览器中完成，再等待程序继续。

GUI 会读取项目文件夹中的 `config`。如果没有这个文件，首次保存会根据 `config.example` 创建它。普通使用无需手动编辑配置文件。“视频学习”中的浏览器选择同时用于视频学习和章节测试，保存后会在下次启动时恢复。

## 使用章节测试

只进行视频学习时无需配置模型。生成章节答案需要支持图片输入的模型接口。

### 接入自己的模型服务

目前支持 **OpenAI 兼容的 Chat Completions 接口**，使用 Key 认证、非流式返回，并接受 Base64 图片输入。原生 Anthropic Messages、Gemini 和 Responses API 暂不能直接接入；服务商提供兼容接口时，请使用其兼容接口地址。

模型需要能读取题目截图、理解选项，并按提示输出包含答案和置信度的 JSON。用户无需编写提示词；程序会自动构造请求。模型名称可以直接在下拉框中输入，不限于预设列表，但名称出现在列表中不代表你的服务商支持它或它具备图片能力。

DeepSeek 官方和硅基流动可选择适配器 `auto`，程序按官方域名识别；也可手动选择 `deepseek` 或 `siliconflow`。DeepSeek 填 `https://api.deepseek.com`，硅基流动填 `https://api.siliconflow.cn/v1`，模型名称以各平台实际提供的名称为准。硅基流动只填官方域名时会自动补齐 `/v1`。

其他服务首次接入可选择通用适配器 `generic` 和输出约束 `prompt`。地址填写实际基础地址或完整的 `/chat/completions` 地址；未知服务不会自动补 `/v1`。具体模型是否支持图片仍需确认，服务商协议适配不代表所有模型均可读图。

保存后，可在“章节测试”中选中对应模型，再到“模型设置”点击“测试所选模型接口（自制图片）”。这会向配置的服务发送一张自制图片，可能产生接口费用。通过测试表示这次请求和简单读图正常，不保证所有章节都能答对。详细的协议、返回示例和错误说明见 [模型接入与中继](docs/llm-relay.md)。

### 操作步骤

1. 在“模型设置”中填写接口地址、Key 和模型名称，保存配置。
2. 切换到“章节测试”，点击“读取章节”，勾选需要处理的章节。
3. 先选择“生成答案预览”，再点击“开始所选章节”。
4. 在“运行记录与答案”中查看答案与置信度，必要时双击题目手动修改。
5. 选中需要处理的记录，执行回填暂存或交卷。

| 模式 | 执行内容 |
| --- | --- |
| 生成答案预览 | 读取题目并调用模型，保存本地答案 |
| 回填并暂存 | 将可用答案填写到网页，并保存作业 |
| 自动交卷 | 填写可用答案并执行交卷，结果以网站确认成功为准 |
| 仅导出题目 | 保存题目与截图，供后续查看 |

“覆盖已有答案”默认关闭。切换模型后，内容一致的高置信度和手动答案会保留，只补低置信度、失败或空答案。低置信度题目会跳过，其他可用答案继续处理；置信度是模型的自评，不等于题目的实际得分。

调用模型时，相关题目截图和选项会发送到你配置的模型接口。批量操作共用一个所选浏览器的会话，单章失败后继续后续章节；出现验证时会等待手动完成。

## 配置与常见问题

**配置文件在哪里？**

就在项目文件夹中，文件名为 `config`，没有扩展名。可用记事本或其他文本编辑器打开，内容仍是分段的文本配置。模板 `config.example` 不包含账号或模型密钥，实际配置不要上传到公开仓库。

**Chrome / Edge 找不到，或安装在其他位置？**

在“视频学习”中选择浏览器，通常将旁边的可执行文件路径留空即可；安装在其他位置时，填写对应的 `chrome.exe` 或 `msedge.exe` 路径。Chrome 可在 `chrome://version`、Edge 可在 `edge://version` 查看可执行文件路径。切换浏览器会清空旧路径，请按需重新填写；若之前启用了连接已有浏览器，也会关闭该模式，改为启动所选浏览器。命令行用户可在 `config` 的 `[browser-option]` 中设置 `driver = Chrome` 或 `driver = Edge`，以及 `EXE_PATH`。无需额外安装 ChromeDriver 或 EdgeDriver。

**视频能进入，章节测试却要求登录？**

视频网站和测试网站的登录状态可能不同。程序会先确认课程页会话，再进入测试；需要重新登录或验证时，请在程序打开的浏览器中完成。

**模型失败，或题目没有生成答案？**

先查看 GUI 日志中的错误。接口地址、Key、余额及模型的图片能力都会影响请求；可以选中失败题重试或切换模型。模型列表里的名称也需要你的服务商实际支持。

**去哪里找结果和日志？**

运行记录可以在 GUI 中查看，日志保存在 `logs`。为兼容已有答案和截图，历史记录继续保存在 `.autovisor` 文件夹。分享诊断记录前，请移除账号、密钥、Cookies 和带登录凭证的链接。

**哪些课程可以使用？**

目前适配智慧树的智慧共享课、翻转课和融合共享课视频页面；章节测试只处理已适配的作业页面和题型。AI 课程、非视频章节及其他页面不能保证支持。页面改版或出现未适配验证时，需人工处理。

## 交流与二次开发

欢迎 Fork 本项目进行二次开发，改进界面、扩展功能、适配更多课程页面或模型接口！也欢迎通过 [Pull Request](https://github.com/pioneerLu/SJTUAutoCourse/pulls) 分享你的改进。项目使用 [MIT 许可](LICENSE)，修改和分发时请保留相关版权及许可声明，包括 [NOTICE](NOTICE) 中的上游声明。

遇到 Bug、有功能建议，或想交流使用体验，都欢迎 [提交 Issue](https://github.com/pioneerLu/SJTUAutoCourse/issues)。反馈问题时，尽量提供：

- Windows、Python 及所用浏览器的版本。
- 复现步骤、预期结果和实际表现。
- 相关错误日志或截图；模型接口问题可注明服务商和模型名称。

提交前请遮盖账号、密码、API Key、Cookies、个人信息以及链接中的登录凭证，不要直接上传完整的 `config` 或 Cookies 文件。
